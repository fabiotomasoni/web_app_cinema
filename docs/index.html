Installa Cineming

Su iPhone: apri in Safari → Condividi → Aggiungi alla schermata Home. Su Mac: Safari → File → Aggiungi al Dock (macOS Sonoma o successivo).

Su Android con Chrome: apri Cineming in Chrome, tocca il menu ⋮ → Installa e crea scorciatoia → Installa e conferma seguendo le istruzioni sullo schermo. In alcune versioni di Chrome la voce si chiama Aggiungi a schermata Home → Installa. Potrai poi aprire Cineming dall’icona sul telefono.

I dati già caricati restano consultabili offline. Gli aggiornamenti richiedono una connessione.
